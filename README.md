## ✨ О проекте

Интерактивный розыгрыш и кастомайзер для iPhone, выполненный в точном соответствии с гайдлайнами Apple (**Human Interface Guidelines**). 

При запуске интерфейс изначально перевернут вверх ногами: если перевернуть iPhone физически в руках, настоящий вырез («челка» или островок) окажется снизу и не будет мешать, а сверху на чистом экране появится кастомный **Dynamic Island**, который можно настраивать в реальном времени.

## 🔥 Основные фишки

* 🔄 **Режим 180° (Upside-Down):** Изначальный разворот интерфейса, превращающий нижнюю рамку телефона в верхнюю часть экрана с кастомным островком.
* 🌈 **RGB-подсветка:** Плавная переливающаяся неоновая анимация островка со свечением.
* 🎨 **Свой цвет:** Встроенная палитра для заливки Dynamic Island в любой оттенок с автоматическим подбором внешнего свечения (`box-shadow`).
* 🖼️ **Своя картинка:** Возможность загрузить любое фото или мем прямо из галереи iPhone внутрь островка (через `FileReader API`).
* 📷 **Реалистичная линза и индикатор:** Детализированный объектив фронтальной камеры с бликами и отключаемая зеленая точка активности камеры/микрофона iOS.
*  **Нативный дизайн Apple:** Системные шрифты `SF Pro Display` / `SF Pro Text`, оригинальные векторные иконки **SF Symbols (SVG)** и плавная физика тумблеров.
* 📱 **Полноэкранный PWA:** Работает без адресной строки и рамок Safari при добавлении на рабочий стол.

## 📲 Как установить на iPhone (На экран «Домой»)

Чтобы приложение открывалось на весь экран как настоящие системные «Настройки»:

1. Открой ссылку на проект в браузере **Safari** на iPhone.
2. Нажми кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх в нижней панели).
3. Пролистай список вниз и выбери **«На экран "Домой"»** (*Add to Home Screen*).
4. Нажми **«Добавить»** в правом верхнем углу.
5. Запусти появившуюся иконку **«Настройки»** с рабочего стола и переверни телефон!
